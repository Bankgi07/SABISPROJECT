> **โครงงานบูรณาการรายวิชา:**
> - System Analysis and Design (SA - ผศ.ดร. อรวรรณ เชาวลิต)
> - Business Information Systems (BIS - อ.ดร. เสาวลักษณ์ อร่ามพงศานุวัต)
> 
> ภาควิชาคอมพิวเตอร์ คณะวิทยาศาสตร์ มหาวิทยาลัยศิลปากร (ภาคเรียนที่ 1 / 2569)

## 🚀 วิธีเปิดใช้งานโปรเจกต์ (Quick Start)

### วิธีที่ 1: ดับเบิ้ลคลิกไฟล์เดียว
ดับเบิ้ลคลิกที่ไฟล์ **`start_project.bat`** (ระบบจะรัน Backend และ Frontend พร้อมเปิดเบราว์เซอร์ให้ทันทีที่ `http://localhost:5173`)

### วิธีที่ 2: รันผ่านคำสั่ง
```bash
npm start
```
